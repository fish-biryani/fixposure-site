Fixposure サポート

Fixposureは、シャッター時間・ISO・露出補正・色温度をそれぞれ個別にAuto/固定できるマニュアルカメラアプリです。

主な機能

  • シャッター時間 / ISO / 露出補正 / 色温度の個別ロック
  • 擬似ボケのポートレートモード(F値・玉ボケ調整・多段ボケ)
  • 撮影設定のテキスト・写真(EXIF)での書き出し / 読み込み
  • 撮影場所ごとの設定プリセット(地図連携)
  • 動画撮影、静音撮影、グリッド、ヒストグラム ほか

よくある質問

Q. F値が変更できません
iPhoneのレンズは絞りが固定のため、F値は物理的に変更できません(表示と記録のみ)。ポートレートモード中のみ、ボケの強さとして擬似F値を調整できます。

Q. ポートレートモードのボタンが表示されません
ポートレートは深度データが必要なため、2眼以上のカメラを搭載した機種でのみ利用できます。

Q. 設定の意味がわかりません
各スライダーはドラッグ中に説明が表示されます。画面左上の「?」からアイコンの説明一覧も確認できます。

プライバシーポリシー / Privacy Policy

Fixposure Support

Fixposure is a manual camera app where shutter speed, ISO, exposure bias, and color temperature can each be individually set to Auto or locked.

Features

  • Independent locks for shutter speed / ISO / exposure bias / color temperature
  • Portrait mode with simulated bokeh (f-number, bokeh-ball tuning, multi-level blur)
  • Export / import capture settings as text or via photo EXIF
  • Location-based setting presets with a map
  • Video recording, silent capture, grid, histogram, and more

FAQ

Q. I can't change the aperture (f-number)
iPhone lenses have a fixed aperture, so the f-number cannot be changed physically (display and metadata only). In portrait mode you can adjust a simulated f-number as the blur strength.

Q. The portrait mode button doesn't appear
Portrait mode requires depth data and is available only on devices with two or more rear cameras.
